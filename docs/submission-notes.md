# Submission Notes

## Project summary

ArcGuard is a custom public GitLab Duo flow and companion demo app that produce a Merge Confidence Report for merge requests.

## Why it fits the hackathon

- Built for the GitLab Duo Agent Platform
- Uses a real MR trigger and a real MR action
- Focused on software delivery workflow quality
- Fully local demo path included
- Public-repo-ready documentation and license included

## What the flow actually does

- reacts to MR mention or reviewer assignment
- runs the shared ArcGuard analysis engine
- computes category scores and a final verdict
- posts a markdown report back into the merge request

## Sustainability angle

ArcGuard includes CI waste scoring and recommendations so the submission can compete for sustainability-oriented judging criteria without relying on placeholder environmental analytics.
