# ArcGuard Flow Instructions

This repository contains the ArcGuard merge confidence system.

When GitLab Duo runs inside this repository:

1. Use the shared analysis engine instead of inventing findings.
2. Run `pnpm arcguard:analyze:flow` to generate the authoritative report.
3. If the merge request description contains `arcguard-scenario: <scenario-id>`, the flow script will hydrate the matching seeded demo scenario.
4. If no scenario marker is present, the flow script falls back to heuristic analysis from `AI_FLOW_CONTEXT`.
5. Post the markdown report generated by the script. Do not rewrite the score or verdict by hand.
6. If the script fails, report the failure clearly and stop. Do not fabricate a confidence report.

ArcGuard verdicts:

- `Safe to Merge`
- `Needs Fixes`
- `Blocked`
