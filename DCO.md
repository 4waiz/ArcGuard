# Developer Certificate of Origin

ArcGuard uses the Developer Certificate of Origin sign-off process.

When you create a commit, add a sign-off line:

```text
Signed-off-by: Your Name <you@example.com>
```

Example:

```bash
git commit -s -m "Add rollback risk scoring adjustments"
```

By signing off, you certify that you have the right to submit the work under
the project license.
